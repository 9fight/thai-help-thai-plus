# ไทยช่วยไทย พลัส 60/40 Calculator

Single Page Web App สำหรับช่วยคำนวณสิทธิร่วมจ่าย 60/40 โดยไม่ใช่แอปทางการของรัฐ ไม่มี backend และข้อมูลประวัติอยู่ใน localStorage เท่านั้น

## Run

```bash
npm install
npm run dev
npm run build
```

## ข้อมูลที่ใช้

- ชื่อโครงการที่ยืนยันจากเว็บทางการ/ข่าวกระทรวงการคลัง: `ไทยช่วยไทย พลัส (60/40)`
- รัฐสนับสนุน 60% ประชาชนจ่าย 40%
- สิทธิรัฐช่วยไม่เกิน 200 บาท/คน/วัน
- สิทธิรัฐช่วยไม่เกิน 1,000 บาท/คน/เดือน
- ระยะเวลาใช้สิทธิ 1 มิถุนายน - 30 กันยายน 2569
- จำนวนผู้เข้าร่วมสูงสุด 30 ล้านคน สำหรับกลุ่ม 60/40
- กรอบวงเงินโครงการ 60/40 จำนวน 120,000 ล้านบาท
- เวลาใช้สิทธิรายวัน 06.00 - 23.00 น.
- ลงทะเบียนประชาชน 25 - 29 พฤษภาคม 2569 เวลา 06.00 - 22.00 น.
- ฟู้ดเดลิเวอรี 15 มิถุนายน - 30 กันยายน 2569 เวลา 06.00 - 21.00 น.
